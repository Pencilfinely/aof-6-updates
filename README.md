# 命术 AOF 6.0 · Windows 测试包

[下载 Windows x64 测试包 v0.6.0-pvp.11](https://github.com/Pencilfinely/aof-6-updates/releases/tag/v0.6.0-pvp.11)

完整解压后运行 AOF6.exe 或「启动命术.cmd」，自带 Godot 和 .NET 运行时。v5 及以后版本通过游戏内更新自动检查、下载、校验并安装；v4 及以前先手动换包。此仓库只发布程序包和版本说明，源码保持私有。

v11 修复卡池「＋」加入：同时显示主牌和备牌数量，合计同名上限满额时从另一区移入一张。新建卡组继承当前色组。两套预组调整法力曲线和核心配合，玩家修改过的官方预组另存「更新前保留」副本；个人卡组、设置、工坊编辑、训练模型和统计保留。

规则采用 3／5。普通识体命中脑区执行两次独立判定，神龙傲天执行四次；每次判定前，命中路与另一路各有三张以上，或命中路已有五张，成功结算才获胜。第一张补到门槛后，第二张可以获胜。自然同步上限三张，曙天护盾仍一次判定。AI 按独立判定及公开牌库剩余量预测本轮进攻，保留有效伤害、费用、守路和资源价值的计算。

使用《命术6.0卡表导入.xlsx》的九十四张可用牌，七十四张带图。支持三路／五路、BO1／BO3、各自选卡组、备牌、投降和断线判胜。协议为 `aof-pvp-5`，联机双方使用 v11 及一致卡表与规则。
